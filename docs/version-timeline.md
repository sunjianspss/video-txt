# video-txt 版本时间线

一句话概括：`video-txt` 从三个需要人工串联的脚本，逐步升级为支持字幕质量控制、多音轨、术语管理、
可复现项目状态和局部修复的长视频生产工具。

完整升级内容与使用示例见 [CHANGELOG.md](../CHANGELOG.md)。

## 版本节点

| 版本 | 时间 / Git 证据 | 生产能力 | 最短使用入口 |
| --- | --- | --- | --- |
| v0.1.0 | Git 历史前；根据兼容脚本还原 | 三个脚本分别完成转写、翻译、封装 | `uv run --python 3.12 python transcribe_media.py "$V"` |
| v0.2.0 | 2026-08-11，`5868e08` | 统一 `transcribe / translate / mux / run / dub`，支持软硬字幕、dry-run、重试、续传和缓存 | `uv run --python 3.12 video-txt run "$V" --provider lmstudio --mux-mode hard` |
| v0.2.x 增强 | 2026-08-11～17，`2c6e886`～`3eb6d71` | 整句配音、多角色音色、原声克隆、背景声分离、本机翻译、质量与资源保护 | `uv run --python 3.12 video-txt dub "$V" --provider lmstudio --diarize --separate-bgm` |
| v0.3.0 | 独立发布提交不可审计；首次完整见 `4715393` | 用词级时间戳把 Whisper 窗口重建为可读字幕 | `video-txt run ... --refine-subtitles` |
| v0.3.1 | 独立发布提交不可审计；首次完整见 `4715393` | 检测字幕缺陷，只自动修复高置信问题 | `video-txt audit source.srt` / `video-txt clean source.srt -o clean.srt` |
| v0.4.0 | 独立发布提交不可审计；首次完整见 `4715393` | 自动避开评论与无障碍解说轨，歧义时要求确认 | `video-txt transcribe "$V" -f srt --language en --audio-stream 2` |
| v0.5.0 | 独立发布提交不可审计；首次完整见 `4715393` | 术语提示、批准译法规范化和独立翻译审计 | `video-txt translate source.srt --term-file project.terms.json` |
| v0.6.0 | 2026-08-24，`4715393` | 配置与运行状态分离，按内容和阶段配置判断失效范围 | `video-txt project init` → `status` → `run` |
| v0.7.0 | 2026-08-24，`87ceaea` | 按时间或字幕序号局部重识别，并生成修复报告 | `video-txt retranscribe-range ... --from ... --to ...` |
| v0.7.1 | 未发布，能力已在 main 上 | 只翻译变更过的字幕，配音与审计若干修复 | `video-txt translate source.repaired.srt --reuse source.srt` |

表中省略的命令前缀统一为 `uv run --python 3.12`。

## 能力增长

| 阶段 | 工作方式 | 人工成本的主要变化 |
| --- | --- | --- |
| 原型 | 三个脚本手工串联 | 人工决定每一步输入输出 |
| 一体化 | 一条命令跑完整流水线 | 支持失败恢复和阶段复用 |
| 质量控制 | 转写时精修，已有字幕可审计和安全清理 | 从“发现成片有问题”提前到“字幕阶段阻断” |
| 长片一致性 | 自动选音轨、统一术语并审计译文 | 减少选错语言、角色名漂移和漏译 |
| 可复现项目 | 配置、状态、内容指纹和失效传播 | 可以解释为什么某阶段需要重跑 |
| 局部修复 | 只重识别错误区间 | 长片小改不再重跑全片 Whisper |

自动化测试从 v0.2.0 快照的 87 项增长到 v0.7.0 的 475 项，main 上当前 496 项。

## 历史边界

- 仓库当前没有 Git tag；版本节点以提交中的版本号和发布提交说明为准。
- v0.1.0 没有可审计快照，只有 v0.2.0 保留的三个兼容入口可用于还原使用方式。
- v0.3.0、v0.3.1、v0.4.0、v0.5.0 没有各自独立的发布提交，它们在 v0.6.0 发布提交中首次完整可见。
- v0.7.1 尚未发布；其内容见 CHANGELOG 的 Unreleased 一节，不属于 `0.7.0` 标签下的软件能力。
