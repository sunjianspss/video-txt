字幕审计怎么用

像体检：先只检查，再决定要不要生成清理副本。

第一步：检查 uv run --python 3.12 video-txt audit "/绝对路径/字幕.srt"
第二步：清理 uv run --python 3.12 video-txt clean "/绝对路径/字幕.srt" -o "/绝对路径/字幕.clean.srt"
1

先把字幕交给检查命令

2

原字幕不动，只生成问题清单

3

需要时，再生成一份清理副本

你会看到的几个词

大白话命令里的名字
只检查、列问题audit
另存一份安全清理版clean
问题和修复记录audit.json
新字幕保存位置-o / --output
